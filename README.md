# Vera ARK

Vera ARK is the integration concept for giving Vera a governed interface to ARK.

## Current status

The current `main` branch is a scaffold: it contains repository governance/licensing and this orientation README, but no implemented ARK integration yet.

Future implementation should make the transport, authentication, authority, data-flow, and runtime boundaries explicit rather than treating “Vera can use ARK” as a single undifferentiated capability.

## Evidence boundary

This repository establishes project intent only. It does not prove an installed bot, a live ARK session, or runtime access.
